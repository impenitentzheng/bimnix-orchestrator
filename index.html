What 0.19 adds

Coordinate foundationกรอบพิกัดกลางสำหรับ building-local, project, survey grid และ reference sources โดยรักษา legacy behavior ที่ตั้งใจไว้
IFC georeferencingIfcProjectedCRS + IfcMapConversion เมื่อข้อมูลครบและผู้ใช้ยืนยันแล้ว พร้อม Case A / A-site เมื่อยังไม่ควรอ้าง georeferencing
Far-origin handlingตรวจพิกัดไกล เสนอ base shift ให้ผู้ใช้ยืนยัน และแก้ปัญหา DXF พิกัดใหญ่โดยไม่ย้ายข้อมูลอัตโนมัติ
No CRS guessingEPSG, MapUnit, True North และ vertical relation ต้องมาจากข้อมูลที่มีที่มา ไม่เติมค่าจากการคาดเดา
Round-trip disciplineCRS จาก IFC ภายนอกถูก stage เป็นข้อมูลที่ยังไม่ยืนยัน; BIMNIX จะไม่ยกสถานะความเชื่อมั่นให้ไฟล์ภายนอกเอง
QTO invariantsการเปลี่ยนกรอบพิกัดไม่ควรเปลี่ยน geometry-local หรือ quantities และถูกตรวจแยกจากการแสดงผล
